MetacatUI 2.36.0


Abstract

MetacatUI is a client-side web interface for querying Metacat servers and other servers that implement the DataONE REST API. Currently, it is used as the basis for the KNB Data Repository, the NSF Arctic Data Center, the DataONE federation, and other repositories in the DataONE network.

MetacatUI is an open source, community project. We welcome contributions in many forms, including code, graphics, documentation, bug reports, testing, etc. Use the discussion list to discuss these contributions with us.




Plain-text abstract

MetacatUI is the front-end (user interface or "UI") component of the Metacat scientific database repository software suite. Metacat and MetacatUI are the backbones of most DataONE repositories. They are both open-source and community-supported software.
